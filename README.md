# Resume Page

This repository contains the code for my personal resume/CV website built with HTML, CSS, and minimal JavaScript. The live version can be viewed at [https://avina5hkr.github.io/](https://avina5hkr.github.io/)

## Features

- Responsive design that works on all devices
- Modern UI with glassmorphism effects
- Animated section entrances
- Clean two-column layout
- Print-friendly styling
- Skills section with flexible tag sizing
- Subtle background animations

## Technologies Used

- HTML5
- CSS3 (with animations and flexbox/grid layouts)
- Font Awesome icons
- Google Fonts (Inter & Poppins)

## Local Development

To run this project locally:

1. Clone this repository
2. Open `index.html` in your browser

No build tools or dependencies are required as this is a static HTML/CSS site.

## Customization

Feel free to fork this repository and customize it for your own resume:

1. Update the personal information in the header section
2. Modify the experience, education, and awards sections
3. Update the skills tags with your own expertise
4. Adjust colors and styling in the CSS

## About This Project

This project replaces the previous simpler version of my portfolio site with a more comprehensive and visually appealing professional resume. The previous version contained basic information about me as a software developer based in Jaipur, India.
